With the increasing demand for seafood consumption worldwide, the concept of Aquaculture is increasing, and the need to sustain the quality of water in the RAS has therefore emerged to be a challenge. Of the different types used, the RDF is identified to be one of the most efficient and effective mechanical filters used to remove suspended matter. Yet, the most efficient ones are relatively pricey, and there are no open-source options currently available for the small-scale implementation that the project addresses. The project, therefore, aims to design and implement the Smart Rotary Drum Filter and IoT-Based Control System. The system will make use of the ESP32 microcontroller, which will enable the automated backwashing process depending upon the real-time levels obtained from sensors and the programmed timer. Moreover, the system will also enable remote controlling and monitoring through the use of a mobile app, thereby increasing efficiency and minimizing the manpower aspect.


Keywords: RAS, RDF, Suspended Solids Removal, IoT-based Control, ESP32 Microcontroller, Automated Backwash, Remote Monitoring.
